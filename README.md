# Calculadora de Peça 3D

Calcula o custo e o preço de venda de peças impressas em 3D: filamento, energia, desgaste da impressora, manutenção, falhas, mão de obra e taxa de marketplace.

- Funciona no navegador, sem servidor; os dados ficam salvos no próprio aparelho.
- Cole o texto do modelo (MakerWorld, Printables, Thingiverse ou do fatiador) e toque em **Ler valores** para preencher peso e tempo.
- No iPhone: abra no Safari → Compartilhar → **Adicionar à Tela de Início**.
